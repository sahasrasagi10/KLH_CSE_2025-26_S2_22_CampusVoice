# CampusVoice

## Campus Improvement & Feedback Platform

**CampusVoice** is a campus improvement and feedback platform designed to provide a centralized way for students to submit, search, support, and track suggestions related to academics, infrastructure, placements, clubs, canteen, and other campus facilities.

The platform aims to reduce duplicate suggestions, identify the most requested improvements, and improve communication and transparency between students and the administration.

---

## Problem Statement

Student suggestions are often collected through different channels such as paper forms, emails, verbal communication, or multiple online platforms. This can result in:

* Repeated or duplicate suggestions
* Poor organization of feedback
* Important concerns being overlooked
* Difficulty in prioritizing student requests
* Lack of transparency about suggestion status

CampusVoice addresses these issues through a centralized feedback platform.

---

## Key Features

### 1. Submit & Categorize Suggestions

Students can submit suggestions and categorize them under areas such as:

* Academics
* Infrastructure
* Placements
* Clubs
* Canteen
* Other campus services

### 2. Smart Search & Duplicate Detection

Students can search existing suggestions before submitting a new one. The system can identify similar requests and recommend existing suggestions to reduce duplicates.

### 3. Upvote Suggestions

Students can upvote existing suggestions instead of creating duplicate requests. This helps identify the improvements that are most requested by students.

### 4. Track Suggestion Status

Students can monitor the progress of their suggestions through statuses such as:

`Pending → Under Review → Approved → Implemented`

### 5. Admin Dashboard & Analytics

Administrators can review and manage suggestions, prioritize requests, update their status, and view insights such as top-voted suggestions and category-wise trends.

## DSA Concepts Used

Data Structures and Algorithms are an important part of the project for efficiently managing and processing suggestions.

| DSA Concept                     | Application                                            |
| ------------------------------- | ------------------------------------------------------ |
| **HashMap**                     | Fast student and suggestion lookup                     |
| **Trie**                        | Efficient keyword-based suggestion search              |
| **Priority Queue / Max Heap**   | Ranking top-voted suggestions                          |
| **Merge Sort / Quick Sort**     | Sorting suggestions by votes or date                   |
| **Hashing + String Similarity** | Detecting similar or duplicate suggestions             |
| **Graph** *(Optional)*          | Representing relationships between related suggestions |

The DSA implementation will be developed using **Java**.
